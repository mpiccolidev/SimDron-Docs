PÁGINA 36 FX permite colocar y disparar efectos visuales sincronizados.

FX

FX permite colocar y disparar efectos visuales sincronizados. Selección del efecto El instructor elige qué FX quiere utilizar. Modos posibles El sistema de SimDron contempla conceptos como looping persistente, one shot manual y one shot auto repeat

COLOCAR Activa un modo de posicionamiento. El efecto se ubica sobre la superficie detectada. Se utiliza un offset aproximado de: +0.5m TRIGGER / DISPARAR Activa el efecto cuando corresponde. Especialmente importante para efectos One Shot como explosiones. CLEAR / LIMPIAR Desactiva o retira el efecto. ESCALA Cuando el efecto lo admite puede ajustarse el tamaño. Función práctica Añade eventos visuales controlados por el instructor sin modificar permanentemente la escena.
