# SimDron / Mission Control — Knowledge Base v2 (28/10/2026)

Rediseño basado en comentarios de revisión de octubre de 2026.

## Prueba local
1. Extraer el ZIP completo.
2. Abrir `manual/index.html` con Chrome o Edge.
3. Elegir **SimDron VR** o **Mission Control** en la barra superior.
4. Abrir solo la sección necesaria con el árbol izquierdo y consultar las páginas/referencias a la derecha.
5. Cambiar Claro/Oscuro desde arriba (se recuerda en este navegador).

## Cambios
- Árbol de navegación por secciones, expandible y con una sola sección abierta a la vez.
- Dos manuales siempre visibles arriba (también en móvil).
- Tres columnas clásicas: índice > artículo > referencias.
- Anterior / Siguiente al **principio** de cada capítulo.
- Fuentes PDF enlazadas con `target=_blank`, sin visor ni PDF embebido.
- Recortes dudosos sustituidos por reproducción **completa** de la página, en especial diagramas OSD y láminas técnicas.
- Eliminación de datos de prueba con `0000`, tablas de relleno y extracción irrelevante cuando se detectó automáticamente.
- Fuente central más legible, párrafos normalizados, imágenes limitadas en altura.

## IMPORTANTE: permisos de PDF
Los enlaces PDF apuntan a los originales **privados de Google Drive** cargados por el autor. La vista funciona en el navegador autenticado del propietario, pero **no estará disponible para público general** sin una decisión explícita de publicación. Para GitHub Pages se necesitará publicar una versión sin datos identificatorios bajo una URL accesible y sustituir los enlaces de `PDF` en el generador o en HTML.

## Restricciones
Esta entrega es una revisión sustancial de UX, no una corrección técnica revisada frase a frase. La conversión automática sigue requiriendo control editorial sobre tablas e imágenes. El archivo PDF y la web comercial original no fueron modificados.
