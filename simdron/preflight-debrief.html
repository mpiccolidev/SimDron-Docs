Preflight Check-In

En la escena de montaje puede encontrar también una planilla tipo multiple choise en una de las pantallas de 65". Este genera de manera aleatoria las preguntas y las posibles respuestas para cada sección, luego se puede validar y exportar. Su objetivo es bajo la estructura gamifica ofrecer al alumno una manera de generar conciencia sobre los pasos previos al vuelo.

Debriefing

Esta escena le permite generar un informe autogestionado posterior a la ejecución de los ejercicios, de esta manera se completa así la EBS (Estrategia Basada en la Simulación) dentro de la propia aplicación para alumnos que ya están más avanzados

Campos a completar

Los campos de información se pueden completar con teclado, utilizando la tecla tab para pasar de uno a otro o empleando el método poke o ray para posicionar el cursor en cada uno de ellos. Puede visualizar informes anteriores, generar uno nuevo, borrarlo o exportarlo en .txt para luego conectar el Meta Quest a una PC y descargarlo desde la ruta que se indica en pantalla
